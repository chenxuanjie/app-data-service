4 项客户端实验分别验证：

1. 无登录/无服务连接时写入，关闭再打开保留数据、客户端 ID 与待上传队列。
2. 离线编辑和删除，关闭再打开仍保留待上传操作。
3. Drift 经连接适配读取 PowerSync 的表视图，避免重复建表；关闭 Drift 不误关 SDK。
4. 未连接服务时，PowerSync watch 查询仍响应本地更改。
